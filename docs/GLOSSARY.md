# Glossary

- **Clock factor**: How slowly the midnight countdown runs. 1 is real time. A higher factor gives more time.
- **Streak**: The number of items caught in a row, with no obstacle hit.
- **Discount code**: A unique string such as `SYL-XXXX`. Hotel staff can check it with the nickname.
- **Mock backend**: An in-memory score store used when Supabase is not configured.
- **Referral**: A personal link `?ref=CODE`. Five finished rounds by distinct new players can raise the discount from 10 % to 20 %.
- **Sandcastle loop**: The local Podman loop that implements one GitHub issue, opens a PR, and does not merge.
