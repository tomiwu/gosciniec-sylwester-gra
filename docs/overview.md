# Overview

`gosciniec-sylwester-gra` is a small web game for the New Year Eve 2026/2027 offer of hotel Gosciniec Uniejow.

The player moves a dancing couple, catches falling items, and avoids obstacles. A catch streak slows the clock. At midnight the player sees the offer and a booking link. A good score gives a unique discount code.

The app is static. A mock backend works on a laptop. Supabase holds the leaderboard when credentials exist.

Read `docs/PRD.md` for requirements. Read `README.md` to run the game locally.
